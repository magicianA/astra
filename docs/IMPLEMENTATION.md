# Astra 0.1 实现与验证

2026-09-04 开始实现，2026-09-05 UTC 完成本机验证。用户授权实现，并明确 Windows 和 Linux 暂不测试。

## 可运行交付

`dist/Astra.app` 是随附数据的本机 arm64 应用，约 3.4 GiB。包含 Vulkan Loader、MoltenVK、SDL3、ERFA、libpng、Noto 字体、SPIR-V、合并星表、DE441、CIO 和时间数据。CSPICE 静态链接。

应用采用本地 ad-hoc 签名；不是已公证的公开分发包。当前 Homebrew ERFA 库的部署目标为 macOS 26，因此本机应用包也要求 macOS 26。源码的其他平台路径保留，跨平台构建及其他硬件测试尚未执行。

已实现地点输入与收藏、日期/历法/时间尺度、暂停与正反向播放、时间轴、球面广角/透视/鱼眼、鼠标选取、名称/HIP 搜索、跟踪、亮度/大气设置、坐标网、场景保存和 PNG/JSON 导出。搜索范围是当前星等阈值内已计算的对象；提高星等后可搜索更暗目标。

## 架构

| 文件/模块 | 职责 |
| --- | --- |
| `time` | 双段 Julian Date、公历/儒略历、TT/TDB/UT1/UTC/LMT、EOP 与 ΔT |
| `orientation` | 现代 IAU 模型、长期岁差、数值 CIO、地球姿态 |
| `catalog` | 二进制星表、名字、来源和质量标志 |
| `sky` | CSPICE 历表、站心观测、恒星传播、太阳系光行时和视位置 |
| `camera` | ENU 球面广角/透视/鱼眼投影及按帧预计算的相机参数 |
| `scenario` | 配置校验、JSON 保存、数据版本匹配 |
| `app` | 工作线程、取消过期请求、快照交接、输入事件与帧投影缓存 |
| `ui` | 浮动工具栏、设置抽屉、搜索、月球卡片和时间控制 |
| `renderer` | Vulkan 初始化、swapchain、HDR、着色器、同步、ImGui 和 PNG 回读 |
| `scripts` | 官方数据采集、合并、参考比对、格式化和打包 |

计算使用 CPU double；GPU 只接收局部投影与颜色，不接收亿千米绝对坐标。恒星没有按今天的天区位置提前剔除；先传播位置，再判断视场。CSPICE 全局 kernel 池由锁和引用计数管理。

默认亮星模式仍遍历星表做廉价的亮度下界筛选，未实现设计中的分块空间索引。完整 12 等计算在后台进行；不变的快照/相机复用投影结果。

## 界面与月球可见性更新

界面默认收起设置抽屉和坐标网，采用顶部地点/时刻入口、左侧工具栏、右侧月球卡片和底部播放控件。月球卡片显示当地朝向的月相示意、照明比例、高度和距离；放大后的名称与选中标记避开月面。

默认北京 2026-09-04 22:00 LMT 的月球高度为 −3.372°，因此被地平面遮挡。“跳到可观月时刻”在后台仅计算太阳系，以 30 分钟间隔搜索未来 35 天，要求月球高度 ≥ 8°、太阳高度 ≤ −6°、月面照明 ≥ 2%。找到后再计算完整星空，保留地点、历法和时间标准，并对准月球。默认场景得到 23:30 LMT、月球高度 10.597°；该采样建议不等同于精确月出时刻。

新增检查覆盖默认月球在地平线下、可观月条件、地点/时标保留、相机对准、取消请求和极昼无结果。通过实际 macOS UI 操作检查了观月跳转、日期/显示抽屉与搜索。点击位置随按钮事件传入 ImGui，修复没有先发生鼠标移动时沿用旧坐标的问题。最终 300 帧 Vulkan 同步验证错误为 0。

## 连续播放更新

播放帧的太阳系位置与地球姿态使用轻量计算独立更新；恒星 ICRS 视方向继续由后台完整计算刷新，绘制、标签、搜索定位和跟踪共用当前帧的地球姿态。暂停保留最后显示帧，直到停止时刻的完整结果到达，避免退回较早的计算快照。截图只导出暂停后的完整结果。

恒星经过显示亮度阈值时平滑淡出；星点高斯光斑计入像素覆盖以减轻亚像素移动闪烁。快速后台刷新不切换按钮禁用样式，短于 350 ms 的计算不显示进度提示，播放期间不反复显示计算提示。

新增检查验证正反播放每一帧的恒星与月球都在移动，并验证恒星步长连续；优化后的折射向量与角度参考计算一致，方向保持单位长度。北京示例在缓存 540 秒后，亮星视位置相对完整计算的最大差为 0.01161 角秒。此数值仅代表该示例；高倍速或慢速设备导致更旧的恒星缓存时，误差会增加。

本机 3600 倍播放约 600 帧，帧间隔中位数 8.14 ms、p95 9.17 ms；反向一天每秒播放中位数 8.50 ms、p95 8.92 ms。两项均启用 Vulkan 同步验证，错误为 0。日志为 `playback-3600.log` 和 `playback-reverse.log`。

12 等完整星表使用保守视场锥及最大折射余量预筛选，并缓存可标注亮星的索引，避免标签和空选择重复扫描全星表。该模式的播放帧间隔从约 139 ms 降至中位数 45.99 ms、p95 49.30 ms，仍未达到默认星等的帧率；日志为 `playback-mag12-final.log`。实际 UI 已验证月球播放、暂停和精确截图；暂停示例保存在 `playback-paused.png/json`。

## 文字移动更新

ImGui 1.91.9b 的 `ImFont::RenderText` 会截断文字起点的小数部分。星空投影虽然逐帧更新，星名仍按一个逻辑像素跳动；Retina 下相当于两个屏幕像素。新增 `text` 模块在生成字形后恢复共同的小数位移，用于星名、行星名、方位标注及其阴影，不改动第三方源码。月球与选中对象卡片的高度、方位使用固定列位置，数字位数变化不再推移另一列。

文字回归使用实际 Noto 中英文字体，检查 1× / 2× 缩放与负坐标跨零时的连续运动。每帧横移 0.125 像素时，原路径在 64 次帧间转换中停留了 56–57 次；修复后所有字形在每一帧都跟随预期位移，阴影间距和字形 UV 保持一致。核心和文字两组 CTest 均通过。60 倍播放实际运行 605 帧，Vulkan 同步验证错误为 0；日志与截图为 `text-playback.log/png`。

## 恒星光斑更新

去掉恒星光斑半径随亮度增长的映射。未分辨为圆面的天体统一使用标准差 0.5 逻辑像素的高斯光点，绘制范围为 6 倍标准差；亮度经过连续的对数压缩，避免亮星出现大片饱和白斑。像素覆盖仍计入高斯方差并补偿总能量，以保留小数像素移动时的稳定性。这是显示光斑模型，不代表恒星的实际角直径。太阳、月球与已分辨圆面的行星继续沿用角半径和月相绘制。

相同北京默认场景、相同曝光下，牛郎星的横向半峰亮度宽度从 9 个屏幕像素减至 4 个；原始截图为 `stars-before.png` 和 `stars-after.png`。另执行 603 帧连续播放及月球放大检查，均开启 Vulkan 同步验证。

12 等完整星表播放另测得帧间隔中位数 50.56 ms、p95 52.89 ms，仍受全星表处理开销限制；日志为 `stars-mag12.log`。上述图形检查的验证错误均为 0。

## 银河背景更新

银河背景现已实现：`background` 模块由 ERFA 构造 ENU 到银道坐标的单位四元数，随当前帧地球姿态更新。
Vulkan 在天空通道采样 ESA/Gaia EDR3 全天亮度图，按晨昏、月相与高度、消光和光污染调节对比，
地面与鱼眼遮罩继续生效。八个 vec4 恰好使用 Vulkan 保证的 128 字节推送常量空间；背景纹理与
采样器独立于 swapchain，窗口重建时保留。恒星使用零遮挡度的发光叠加，圆面使用预乘透明度遮挡，
修复暗星在亮背景上变成黑点的问题。

坐标回归覆盖 −3000 至 6999 年、多个经度、赤道和两极，与 ERFA 独立球面转换吻合；新开关可保存，
旧场景默认开启，背景版本不匹配会报告错误。实际 GPU 像素对比确认恒星只增加光亮、白天开启与关闭
银河一致。窗口缩放、远古年份、极点、鱼眼和 3600 倍播放的 606 帧回归中，帧间隔中位数 8.15 ms、
p95 9.15 ms，Vulkan 同步验证错误为 0。相关日志和截图以 `milky-way-` 为前缀保存在 `artifacts/`。

背景采用 `gaia-edr3-diffuse-v2` 独立版本及散列清单。它保持固定的遥远银河形态，不模拟恒星群、
暗尘带和银河在一万年内的结构演化，也未对这张低分辨率弥散图逐像素施加大气折射或光行差。
公开亮度图经过小范围中值滤波，尽量减少与独立星点的重叠，但不声称逐源完美去重或绝对辐射定标。

## 银河质感更新

由官网低分辨率下载衍生的 1024×512 模糊背景，更新为 HI-RES 下载的原生 4000×2000 数据。
3 像素中值滤波保留细尘带，不再使用整图高斯模糊。着色器在线性光空间将颜色饱和度保留 35%，
显示强度系数由 0.12 降至 0.065，减弱浓厚的黄褐色与大块亮雾；这是视觉调节，不是绝对辐射或视网膜模型。

新增 `image_mips` 模块：CPU 在线性光空间按面积构建完整的 12 层纹理，不依赖设备的线性 blit 能力。
奇数尺寸的边缘像素也计入面积平均。Vulkan 一次上传所有层并使用三线性过滤；银经 UV 的导数在
接缝处环绕，避免 mip 选择形成模糊条带。新增测试检查黑白平均的 sRGB 结果为 188、透明度线性平均、
奇数尺寸边缘、单行/单列、完整层级与恒定亮度。v1 场景保留设置并迁移到 v2 的显示效果，未知背景版本仍拒绝。

同一日期、相机、曝光下的实际 GPU 对照保存在 `artifacts/galaxy-quality-before.png` 和
`artifacts/galaxy-quality-after.png`。独立恒星位置与亮度参数不受本次背景调整影响。
核心、相机、纹理层级、文字移动四组测试通过；其中纹理检查 207,962 项，核心检查 9,984 项。
3600 倍播放、窗口重建、远古日期、极点、鱼眼及连续环顾共运行 606 帧，Vulkan 同步验证错误为 0；
帧间隔中位数 8.33 ms、p95 9.73 ms。日志为 `artifacts/galaxy-quality-final.log`。

## 天球环顾与银河运动验证

拖动使用固定地平线的方位角/仰角控制，不再自动产生滚转。水平拖动只改变方位，
垂直拖动只改变仰角；按窗口的逻辑像素尺寸及当前投影的角尺度换算，放大后降低角速度。
每次移动都从按下时的相机姿态计算，避免输入采样频率影响结果。
仰角限制为 −90° 至 90°，到达天顶/天底后停止，不翻转观察者。
旧场景的显式滚转值继续保留，可用 R 或“恢复水平”归零。

手势在鼠标按下时按实际位置判定归属，天空手势经过面板时继续旋转；从界面控件开始的手势
不会转动天空。抬起时应用最后位置，短点击保留选星，失焦或窗口尺寸改变会取消未完成手势。

银河仍按每像素视线从 ENU 转为银道坐标并采样全天图，与星点共用相机基底。
在三个固定姿态的实际 GPU 输出中，按相同天球方向重投影约 12 万像素，平均通道差为
0.072–0.074 / 255，99% 通道差小于 0.71 / 255。这确认背景固定在天球方向上，
未发现屏幕空间平移或与相机不同步。对照关闭大气、地面与名称，以排除其他亮度和遮挡因素；
该检查验证几何一致性，不评价主观手感、纹理细节或真实银河辐射亮度。
输入场景、PNG、检查程序与结果保存在 `artifacts/galaxy-motion-*`。

相机回归 **8,920 项通过**：水平保持、方向分离、窗口比例、1° 至 180° 视场、
反向拖动、天顶/天底边界和场景兼容。核心 9,983 项与文字移动 82,432 项检查继续通过。
图形 smoke 增加了连续的对角环顾，603 帧播放、resize、远古日期及鱼眼回归中，
Vulkan 同步验证错误为 0；日志与截图为 `artifacts/pan-final.log/png`。
本机自动化拖动工具之前只向 SDL 交付按下/抬起事件；本次连续视角运动由应用 smoke 路径驱动，
不等同于实际鼠标手感测试。

## 低仰角投影与默认视场

原银河演示采用 110° 垂直视场的直线透视。其径向与切向的局部放大率不同：离轴 65°
处的比值约 2.37，因此细节转到边缘时会被拉成长条。上一版尝试将默认改为球极平面（stereographic）
投影，显示名称为“球面广角（保角）”，但地平线弯曲的观感不符合使用需求，已撤销其默认地位。该投影保持局部角度，但不保持面积；广角边缘仍会
放大，离开画面中心的地平线也会弯曲。这是投影选择的取舍。[Stellarium 投影说明](https://stellarium.org/files/guide.pdf)

CPU 使用 `2 * (x, y) / (|v| + z)` 投影天球方向，GPU 每像素反算同一条射线；垂直视场的
中央比例尺为 `height / (4 * tan(fov / 4))`。恒星、银河、地面遮挡、网格、拾取和拖动采用
相同模式。视锥剔除包括广角角落中超出前半球的射线；太阳、月球和可分辨行星的圆面使用
局部投影比例，未分辨恒星继续保持固定像素 PSF。推送常量仍为 128 字节。

显示面板保留直线透视与全天鱼眼；切换保留相机朝向，必要时限制 FOV。新场景显式保存

## 16K 银河背景升级

保留已接受的 60° 直线透视与拖动行为，仅更新背景数据和纹理采样。旧 4000×2000 Gaia
EDR3 展示图替换为 NASA SVS 的 `milkyway_2020_16k_gal.exr`：原生 16384×8192，
约 1.34 亿像素，为旧图的 16.8 倍。采用 2021-01-04 修正银道坐标后的版本，亮星前景
已由 NASA 分离；动态星表继续单独计算。[NASA 原始数据及制作说明](https://svs.gsfc.nasa.gov/4851/)

离线准备保留原始空间采样，只调整显示亮度、进行 sRGB 编码和极点行平均；不使用中值滤波、
锐化、AI 生成、噪声或放大。原始 EXR 为线性半精度格式，运行资源为 8 位 sRGB PNG，
因此这是空间分辨率升级，不是绝对光度精度升级。新的背景 ID 为
`nasa-gaia-dr2-diffuse-16k-v1`；旧场景可读取，观测时间、地点和相机视角不变。

Vulkan 上传完整的 15 层线性光 mipmap，按硬件能力使用最高 8× 各向异性过滤。
设备最大纹理尺寸不足时，上传最细的受支持 mip 层及其后续层级。完整 16K 链约需
683 MiB 显存；CPU 在上传前释放解码像素以降低峰值。原始 EXR 和 OpenCV 仅供离线
准备使用，运行与应用包不增加 EXR 解码依赖。

细节仍受原始数据分辨率与 Gaia 巡天伪影限制；放大到很窄视场不能产生不存在的新细节。
背景暗星不随万年时间传播，亮星与太阳系天体仍采用动态天文计算。

两者使用相同的地点、时刻、15° 仰角和 60° 直线透视。
四组 CTest 与代码格式检查通过。16K/8× 过滤在播放、窗口调整、远古年份、极点、鱼眼及

## 缩放返回全景的视场上限

初始透视为 60°，但旧滚轮逻辑使用投影公式支持的 150° 上限。放大后向外滚动过量，
或触控板惯性越过 60°，会进入明显拉伸的超广角。原生界面已复现该路径；相同幅度的
60° → 6.4° → 60° 往返本身没有改变投影。

普通透视的交互缩放现在限制在 1°–60°，从其他投影切回透视也采用同一上限。
数学投影仍能读取旧场景明确保存的较宽视场；手动球面广角和鱼眼保留 180° 上限。
没有更改相机朝向、拖动或银河采样。

相机测试新增三种投影各 100 次小数滚轮往返、边角射线复原、缩放极限与过量滚动检查。
四组 CTest 和格式检查通过。macOS 应用实测 60° → 6.4° 后以双倍幅度缩回，停在 60°；
初始和返回截图中排除界面与指针后的 457,200 个像素完全一致。鱼眼 180° 切回透视也恢复
到 60°。证据为 `artifacts/zoom-round-trip-*.jpg`、
`artifacts/zoom-round-trip-image-comparison.json` 和 `artifacts/zoom-projection-return.jpg`。

## 与原始设计的差异及精度边界

- 当前误差显示为位置与自行误差的对角近似；尚未实现完整协方差与距离/RV 不确定性传播。缺失参数和多星/低质量解明确标注。
- Gaia 主包按参考历元的 `G ≤ 12` 提取；未补齐更暗的全部近邻/高速恒星，因此不是任意远期亮度阈值下的数学完备星表。
- 远期使用长期岁差加外推章动，ΔT 采用名义模型。未来/远古地球自转误差、未知极移、恒星轨道扰动和演化没有精密预测。
- 当前亮度混合 Gaia G、Hipparcos Hp 与 BSC V；颜色、大气、行星亮度和圆面相位用于可视化。没有行星表面照片纹理、真实地形、土星环或卫星系统。
- 火星至海王星是 DE441 行星系统质心近似；未声称卫星 SPK 或行星本体中心也有万年覆盖。
- 当前坐标网是地平网，信息面板显示以 ICRS 轴表示的站心视方向；尚未加入独立赤道网。首版不提供精密食/掩星接触时间或望远镜控制。
- Windows/Linux 没有构建、运行或性能验证；macOS 其他硬件和系统版本未测试。
